vnpy (VeighNa) Architecture

事件驱动 + 插件化 — ABC 契约在核心仓（本仓），网关/应用在 VeighNa 生态 pip 包 · v4.4.0

核心契约（trader/）

  • • MainEngine (engine.py:81) — 组装中枢，send_order 按名路由
  • • BaseGateway (gateway.py:33) — 网关 ABC，生态包 vnpy_ctp 等实现
  • • BaseApp (app.py) — 应用 ABC：app_name + engine_class + widget_name
  • • 改动任一签名 = 全生态破坏性变更

事件流（运行时）

  • • 网关回报 on_tick / on_order / on_trade → EventEngine.put()
  • • 各引擎 / UI 经 register(EVENT_*) 订阅回调
  • • 事件名带点号："eTick." 前缀即子事件（eTick.IF2112）
  • • EVENT_TIMER 每秒触发，驱动轮询逻辑

目录速览

  • • trader/ 核心 ~6.5k 行 · event/ 事件总线 153 行（零依赖）
  • • chart/ pyqtgraph K 线 · rpc/ ZeroMQ 分布式
  • • alpha/ 4.4.0 研究栈 — 独立，不依赖 trader
  • • ui/ PySide6 主窗口 + 监控组件（widget.py 1710 行）
